  # Narrative Design System
  
  **Narrative Design** is a minimalist, high-contrast design system built with **Svelte 5**. It focuses on typography, clarity, and a sophisticated aesthetic using a blend of Serif and Sans-serif typefaces.

  ## Design Principles
  
  - **Minimalism**: Remove unnecessary elements to focus on content.
  - **High Contrast**: Use black, white, and subtle grays to create a strong visual hierarchy.
  - **Typography First**: Leveraging *EB Garamond* for narrative content and *Inter* for functional UI.
  - **Responsive by Default**: Every component is designed to work seamlessly from mobile to desktop.

  ## Component Categories
  
  - **Atoms**: Basic building blocks like Buttons, Inputs, and Typography.
  - **Layout**: Structural components like Containers, Headers, and Sidebars.
  - **Overlay**: Contextual layers like Modals, Drawers, and Toasts.
  - **Content**: Specialized editors and data displays (Audiobook Designer, Tables).
  - **Media**: Audio playback and file management tools.

  ## Quality & Standards
  
  - **Accessibility**: All components are tested for WCAG compliance using `@storybook/addon-a11y`.
  - **Testing**: Logic and interactions are verified with Vitest and Storybook's testing addon.
  - **Documentation**: Interactive documentation is automatically generated for every component.

  ## Getting Started
  
  To use Hermes in your project, import components from the library:

  ```typescript
  import { Button, Input, AudiobookDesigner } from '$lib';
  ```

  All components are built using Svelte 5 Runes (`$state`, `$props`, etc.) for optimal performance and reactivity.
