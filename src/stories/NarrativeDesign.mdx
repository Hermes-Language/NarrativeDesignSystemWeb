# Narrative Design System

Hermes Narrative Design System is a narrative-first visual language for content-rich interfaces. It prioritizes reading comfort, editorial clarity, restrained surfaces, and quiet interaction.

<div className="nds-callout">
The system keeps a small semantic foundation that stays stable across light and dark themes.
</div>

## Foundation Principles

- Keep the palette narrow.
- Let surfaces remain quiet and paper-like.
- Use color for meaning, not decoration.
- Preserve strong readability at all times.
- Keep typography serif-led and editorial.
- Use spacing as a structural tool.

## Color

Color defines hierarchy, surface separation, and semantic meaning. The palette is intentionally minimal with strong contrast and low decorative noise.

| Token | Value | Purpose |
| --- | --- | --- |
| `bg-color` | `#f7f3f0` | Main canvas and base background |
| `text-color` | `#000000` | Primary text and strong emphasis |
| `secondary-text` | `#666666` | Supporting text and metadata |
| `border-color` | `#000000` | Structural lines and dividers |
| `panel-bg` | `#ffffff` | Surface background for panels |
| `hover-bg` | `#f5f5f5` | Subtle hover surface |
| `overlay-bg` | `rgba(0, 0, 0, 0.4)` | Backdrop and scrim |
| `accent-color` | `#000000` | Accent and emphasis |
| `error-color` | `#ff4444` | Error and destructive feedback |
| `success-color` | `#4caf50` | Success and positive feedback |
| `info-color` | `#2196f3` | Informational feedback |

## Typography

Typography is the primary expressive foundation. Serif is the dominant voice; sans-serif is used for operational and compact contexts.

| Token | Value | Usage |
| --- | --- | --- |
| `font-serif` | `'EB Garamond', 'Noto Serif SC', serif` | Main narrative voice |
| `font-sans` | `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, sans-serif` | Utility and functional UI |

| Role | Value |
| --- | --- |
| Display title | `4rem` |
| Large heading | `2.5rem` |
| Medium heading | `1.8rem` |
| Body text | `1.2rem` |
| Large body / supporting UI | `1.5rem` |
| Supporting text | `0.9rem` |
| Micro text | `0.85rem` |
| Uppercase label | `0.75rem` |

## Spacing

Spacing supports rhythm, clarity, and calm composition.

| Token | Value | Usage |
| --- | --- | --- |
| `spacing-xs` | `0.5rem` | Tight local spacing |
| `spacing-sm` | `1rem` | Standard spacing |
| `spacing-md` | `1.5rem` | Group spacing |
| `spacing-lg` | `2.5rem` | Section spacing |

## Shape

Shape is intentionally minimal and structural.

| Token | Value | Usage |
| --- | --- | --- |
| `radius-none` | `0` | Default sharp edge |
| `radius-sm` | `0` | Minimal or no rounding |
| `radius-md` | `0` | Minimal or no rounding |
| `radius-full` | `9999px` | Fully rounded pill |

## Motion

Motion is quiet and informative. It supports context changes without drawing attention to itself.

| Token | Value | Usage |
| --- | --- | --- |
| `transition-fast` | `0.15s ease` | Hover and lightweight feedback |
| `transition-normal` | `0.3s ease` | Standard transitions |
| `transition-slow` | `0.4s ease` | Larger layered transitions |

## States

The system uses a restrained semantic state model:

- Default
- Hover
- Active
- Focus
- Disabled
- Selected
- Error
- Success
- Information

State cues should rely on contrast, surface tone, and borders, not decorative effects.

## Layout

Layout is editorial and content-first:

- Keep reading width comfortable.
- Use vertical rhythm to organize narrative flow.
- Keep secondary areas visually subordinate.
- Preserve readability over density on smaller screens.

## Theme

Theme is semantic, not decorative. Light and dark modes share the same roles and hierarchy; only contrast values shift.

## Accessibility

Accessibility is foundational, not optional:

- Keep strong contrast for readable content.
- Do not rely on color alone for meaning.
- Keep focus and disabled states clearly visible.
- Preserve semantics consistently in light and dark.
